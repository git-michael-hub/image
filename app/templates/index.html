Select the color to make invisible:

How the Invisibility Cloak works:

  1. Upload an image of a person wearing clothing of the selected color
  2. The app will detect the selected color and make it invisible
  3. The color will be replaced with the background, creating a "Harry Potter" invisibility effect
  4. For best results, use a solid colored object against a clean background

How Object Censoring works:

  1. Upload an image that might contain sensitive objects
  2. Select the types of objects you want to censor
  3. Choose your preferred censoring method
  4. The app will detect and censor the selected object types
  5. For best results, ensure objects are clearly visible in the image

Language:

How Text Recognition works:

  1. Upload an image containing text (document, sign, screenshot, etc.)
  2. The app will process the image and identify text regions
  3. Optical Character Recognition (OCR) extracts the text content
  4. View both the highlighted text regions and the extracted text
  5. For best results, use clear images with good lighting and contrast
